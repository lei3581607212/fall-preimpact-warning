# Third-party and private data boundary

The repository does not redistribute source datasets, private recordings, or
sample-level pose arrays. Obtain public datasets from their official sources.

| Dataset | Persistent source | Redistribution decision |
| --- | --- | --- |
| CAUCAFall | DOI 10.17632/7w7fccy7ky.4 | CC BY 4.0 verified; attribution and file-level review required for derivatives |
| GMDCSA-24 | DOI 10.5281/zenodo.11489420 | CC BY 4.0 verified; attribution and file-level review required for derivatives |
| URFD | Article DOI 10.1016/j.cmpb.2014.09.005 | Terms not verified; do not mirror raw or derived samples |
| TST Fall Detection Dataset v2 | DOI 10.21227/H2QP48 | Account terms require confirmation; publish provenance and code only |
| Multiple Cameras Fall Dataset | Auvinet et al., DIRO Technical Report 1350 | Terms not verified; do not mirror videos or clips |
| KU Leuven fall simulation data | Official KU Leuven AdvISe dataset page | Terms require confirmation; publish provenance and code only |
| FieldCollection | Private team-enacted collection | No raw media or pose arrays; ethics/consent and release authorization pending |

The `MultiFallEvents` project collection is a composite of selected MCFD and KU
Leuven material, not a seventh independent public dataset. Its clips are not
included. The v2 protocol excludes 15 known aliases between full MCFD videos
and derived event clips before family-disjoint splitting.
